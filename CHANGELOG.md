# Changelog

## 0.1.21 — Bike isolation and calibration polish

- Removed the Dash splash artwork and added a compact RangeBuddy range icon.
- New installs start with no bike; add a catalogue bike explicitly, with confirmation.
- Kept virtual batteries, charge records, saved chargers/places and new ride history scoped to each bike.
- Ride cards now show duration, distance, charge used, and virtual charge from/to values.
- Added delete confirmation for charger/place pills and swiped charge sessions.
- Improved calibration guidance and the active-ride calibration layout with a consistent yellow accent.

## 0.1.2 — Charging, calibration and ride context

- Added Dash, RangeBuddy's battery-bot mascot, for the launcher and app splash screen.
- Added the RangeBuddy hand-lettered wordmark to the branded launch experience.
- Added Jaguar T72L, Leopard F72, Rhino T53, Saibei F71 and Orca F50 baseline profiles to the verified TailG catalog.
- Full charges now record a 7 h 30 min charging session and recover only the missing battery capacity.
- Charge history shows start/end percentage, duration and recovered energy, with month/year/all-time filters.
- Saved chargers and charging places use compact expandable chips.
- Added calibration-mode guidance, yellow calibration ride treatment, universal warning controls and charge protection during calibration.
- Added Battery Health guidance and saved-place pins during active rides.
- Update prompts now show only for newer GitHub releases and use scrollable release notes.

## 0.1.1 — Map and charging list fixes

- Added Android network permission for OpenStreetMap and Google Maps links.
- Improved Google Maps link and full Plus Code location parsing.
- Made saved chargers and places update immediately after changes.
